# Daily Plan — M'Cheyne Readings with Spurgeon Devotionals

Every day of the year: the four M'Cheyne reading slots, and the scripture each
paired devotional is built on.

**Every pairing here is a scripture match.** A devotional appears on a day only
because its own text is drawn from a passage that day reads — the day reading
Genesis 1 gets a devotional on Genesis 1:4. **Bold** marks which reading it
matched.

Days with no matching devotional are left **open** rather than filled with
something unrelated.

The code in the last column (e.g. `06-01-AM`) is the entry's identifier in
Spurgeon's original *Morning and Evening*, kept only so it can be traced back to
its source. It carries no meaning here — pairing ignores the original calendar
date and the morning/evening split entirely.

The M'Cheyne plan runs 365 days and has no February 29, so that day is absent.
